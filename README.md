> Created with educational purpouse

Simple Pokedex App created with React + Vite

Data extracted with [PokeAPI](https://pokeapi.co)
   
## About this project

Project made for practice React State use and APIs consumption.

* **Simple Search:** Look for a 1st GEN Pokemon writing its name
* **Dynamic Pokecards:** Shows a colored background according the pokemon type
* **Complete Data:** List types and pokemon id 
* **Cache:** Save the data to avoid fetch each time.

## Stack

Built with

* **React**
* **Vite**
* **JavaScript**
